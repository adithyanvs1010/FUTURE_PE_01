# FUTURE_PE_01 - AI Website Copy Generator for Local Businesses

## Business Chosen
Glow Beauty Salon

## Objective
To generate professional website copy for a local beauty salon using prompt engineering techniques.

## Repository Structure

- README.md
- prompt.md
- output.md

## Project Description

This project demonstrates how AI can be used to create engaging and professional website content for a local business. Multiple prompts were designed and tested to generate high-quality website copy for Glow Beauty Salon.

The generated content includes:
- Homepage Hero Section
- About Us Section
- Service Descriptions
- Customer Benefits
- Call-to-Action (CTA)

## Prompt Engineering Strategy

- Assigned a specific role to the AI (website copywriter).
- Clearly defined the business type.
- Specified the target audience.
- Defined the desired tone and style.
- Requested structured website sections.
- Generated website-ready content.
